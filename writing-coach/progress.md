# 진행 기록

> 코치와 새 대화를 시작할 때 **'현재 상태'** 칸을 복사해서 첫 메시지에 붙여넣으세요.
> 그러면 세션이 바뀌어도 코치가 어디까지 왔는지 알고 이어서 코칭할 수 있습니다.

## 현재 상태

```
[현재 상태]
- 단계: 0단계 (준비)
- 작품: (가제 / 키워드)
- 이번 주 목표:
- 최근 막힌 점:
- 문체 일지 핵심: (style-journal.md의 확정된 원칙 중 중요한 것 3개)
- 최근 독자 수치 요약: (연재 전이면 비워두기)
```
