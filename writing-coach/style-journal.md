# 문체 일지

> 코치 피드백을 받을 때마다 여기에 정리하세요. 쌓이면 이게 곧 **내 문체 명세서**가 됩니다.
> '확정된 원칙'과 '고칠 습관'은 시스템 프롬프트의 `현재 문체 일지` 칸에 붙여넣어 코치가 기억하게 하세요.
> 나중에 대필 모델을 만들 때도 이 문서를 그대로 지침으로 쓸 수 있습니다.

## 확정된 원칙

내가 받아들이기로 정한 규칙입니다. 확신이 생긴 것만 옮기세요.

| 항목 | 원칙 | 정한 날짜 |
|---|---|---|
| 문장 길이 | 예: 평소에는 짧게 끊고, 감정이 고조될 때만 길게 | |
| 시점 | 예: 수 1인칭, 공의 속마음은 행동으로만 보여줌 | |
| 대사 | 예: 공은 짧고 건조한 반말 / 수는 존댓말이 무너지는 순간을 강조 | |
| 감정 표현 | 예: 감정 단어 대신 신체 반응과 감각으로 | |
| 관계 장면 | 예: 감정선을 먼저 쌓고, 묘사는 구체적으로 하되 같은 단어 반복 금지 | |
| 회차 끝맺음 | 예: 다음 화가 궁금해지는 한 줄로 끊기 | |

## 고칠 습관

자주 지적받는 표현과 버릇입니다.

| 습관 | 예시 | 대체 방향 | 상태 |
|---|---|---|---|
| 예: "~것 같았다" 남발 | "그가 웃는 것 같았다" | 단정하거나 근거를 보여주기 | 고치는 중 |
| 예: 상투 표현 | "심장이 쿵 내려앉았다" | 이 인물만 할 법한 반응으로 | |
