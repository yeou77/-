# 집필 코치

AI가 대신 써주는 게 아니라, **내가 쓰고 AI가 참고 작가와 비교하며 코칭**해서 내 문체와 실력을 키우는 도구입니다.

## 파일

| 파일 | 용도 |
|---|---|
| `system-prompt.md` | AI에 넣을 코치 지침. 한 번만 설정하면 됨 |
| `style-journal.md` | 내 문체 일지. 피드백을 쌓아서 문체 명세서로 키움 |
| `README.md` | 이 문서. 사용법과 요청 예시 |

## 설정 (처음 한 번)

1. `system-prompt.md`의 `---` 사이 내용을 복사합니다.
2. `[ ]` 칸(장르, 목표, 참고 작가 등)을 채웁니다.
3. 쓰는 AI의 시스템 프롬프트 자리에 붙여넣습니다.
   - Claude: 프로젝트를 만들고 **프로젝트 지침**에 붙여넣기
   - ChatGPT: **커스텀 GPT** 또는 프로젝트 지침
   - 로컬 모델(LM Studio, Ollama 등): **System Prompt** 칸
4. 수위가 높은 장면의 첨삭은 상용 AI에서 제한될 수 있으니, 그 장면만 로컬 오픈 모델에 같은 프롬프트를 넣어 쓰세요.

## 요청 예시

요청 첫 줄에 모드를 적으면 됩니다.

### [분석] 참고 작가 장면 분석

```
[분석]
작가: (작가명) / 작품: (작품명) / 장면 종류: 첫 키스 직전의 긴장

(참고 장면 1,000~3,000자 정도 붙여넣기)
```

### [비교] 내 장면과 비교 진단

```
[비교]
장면 종류: 둘 다 '오해 후 재회' 장면

<참고 장면>
(참고 작가 장면)

<내 장면>
(내 원고)
```

> 같은 성격의 장면끼리 비교해야 의미 있는 피드백이 나옵니다.

### [첨삭] 내 원고 첨삭

```
[첨삭]
이번에 신경 쓴 점: 감정 단어 없이 긴장 보여주기
특히 봐줬으면 하는 곳: 마지막 대화 부분

(내 원고)
```

### [과제] 연습 과제 받기

```
[과제]
요즘 약점: 대사가 설명적이고 길다
인물: (내 인물 이름과 간단한 성격)
```

### [일지] 문체 일지 정리

```
[일지]
오늘 대화에서 받은 피드백 정리해줘
```

→ 결과를 `style-journal.md`에 옮겨 적으세요.

## 추천 루틴 (주 단위)

1. **분석** 1회: 참고 작가 장면 하나에서 기법 뽑기
2. **과제** 1~2회: 그 기법을 내 인물로 연습
3. **첨삭** 2~3회: 실제 원고 첨삭
4. **비교** 1회: 이번 주 내 장면과 참고 장면 나란히 보기
5. **일지** 1회: 주말에 정리해서 `style-journal.md` 업데이트

## 지켜야 할 선

- 참고 작품은 **정식으로 구매한 것**만 쓰고, 소설 전체가 아니라 **필요한 장면만 발췌**해서 넣으세요.
- 연습한 글은 **공개하지 않는 연습장**에만 두고, 실제 연재작은 내 설정과 인물로 따로 쓰세요.
- 참고 작가는 **2~3명 이상** 분석하세요. 한 명만 파면 아류가 되기 쉽습니다.
- 가져올 건 **"왜 좋은지"(기법)**이지 문장이나 설정이 아닙니다.

## 나중에 대필 모델로 이어가기

이 루틴을 몇 달 하면 다음이 쌓입니다.

- 직접 쓰고 첨삭받아 고친 원고 → 파인튜닝용 "지시 → 본문" 학습 데이터
- `style-journal.md` → 대필 모델에 넣을 문체 명세서

그때 이 자료로 나를 닮은 대필 모델을 만들면 됩니다.
