위험 영역
설정
Llama는 Meta가 직접 API를 안 줘서, 무료로 빠르게 쓸 수 있는 Groq(console.groq.com)의 키를 써.
데이터 관리 (모든 페르소나·대화·기억 포함)
이 기기에만 저장돼. 다른 기기로 옮기거나 백업하려면 내보내기 한 파일을 구글 드라이브 등에 저장해두고, 새 기기에서 불러오기 하면 돼.
유저노트
대화 중 자동으로 수집된 정보야. 자동 추출이 실패했으면 직접 추가해도 돼.
장기기억
전체 내보내기
모든 페르소나·대화·기억·설정을 파일 하나로 저장해. 저장된 파일은 폰의 "다운로드" 폴더에 생기고, 거기서 구글 드라이브 앱으로 옮기거나 공유하면 백업이 완성돼.
불러오기 (복원)
내보내기로 저장한 JSON 파일을 선택하면 페르소나·대화·기억이 복원돼.
